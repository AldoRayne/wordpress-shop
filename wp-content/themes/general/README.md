
# CheIT Start Theme

## Інсталяція

Для створення копії сайту перейдіть у каталог теми та у WP CLI виконайте команду ```wp general create_site_archive```. Після успішного виконання в кореневому каталозі сайту буде створено архів:


```
  site-archive.zip
├── files
│   └── wp-content
│       ├── uploads
│       ├── themes
│       └── plugins
├── database.sql
└── wpmigrate-export.json

```
Даний архів можна використати для встановлення сайту в середовищі [Local](https://localwp.com/help-docs/getting-started/how-to-import-a-wordpress-site-into-local/#import-a-site)
